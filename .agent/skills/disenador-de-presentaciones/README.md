# Diseñador de Presentaciones 🎨

Esta habilidad permite al agente Antigravity crear presentaciones automáticas en Google Slides basadas en cualquier contenido que le proporciones.

## Capacidades

- **Lectura Inteligente**: Analiza artículos de blog, sitios web o documentos locales.
- **Estructuración Ganadora**: Divide el contenido en diapositivas con una jerarquía lógica (Portada, Agenda, Cuerpo, Cierre).
- **Automatización de Navegador**: Navega a Google Slides y construye la presentación por ti.
- **Diseño Visual**: Sugiere imágenes y utiliza el motor de "Explorar" de Google para dar un toque profesional.

## Cómo usarla

1.  **Desde el chat**: Simplemente di algo como:
    _"Crea una presentación basada en este enlace: [URL]"_
    o
    _"Hazme unas diapositivas sobre este documento que acabo de subir."_

2.  **Proceso**:
    - El agente leerá la fuente.
    - Te mostrará un resumen de lo que ha extraído para tu aprobación.
    - Procederá a abrir el navegador y crear el documento en tu cuenta de Google (asegúrate de que la sesión esté iniciada en el navegador).
