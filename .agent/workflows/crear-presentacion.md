description: crear presentaciones inteligentes en Google Slides
---

Usa este comando cuando necesites que el agente cree una presentación profesional basada en una fuente externa.

1.  Escriba `/crear-presentacion`.
2.  Proporcione el enlace (URL) o el nombre del archivo.
3.  Indique si prefiere algún estilo visual específico (ej: "moderno", "ejecutivo").

El agente analizará el contenido y procederá a construir el deck en Google Slides.
