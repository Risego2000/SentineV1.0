---
description: crear una habilidad de arquitectura de aplicaciones que analice, investigue y cree un PRD operativo
---

Usa este comando cuando quieras iniciar el diseño y desarrollo de una nueva aplicación basada en datos.

1.  Escriba `/crear-habilidad-app`.
2.  Describa brevemente la idea de la aplicación.
3.  Indique si tiene requisitos específicos de seguridad o diseño.

El agente activará la habilidad `arquitecto-aplicaciones`, realizará una investigación profunda y le presentará un PRD detallado para su aprobación antes de proceder con el desarrollo.
