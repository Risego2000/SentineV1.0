Este flujo de trabajo permite al agente realizar un escaneo completo de la actualidad social.

1.  Escriba `/rastrear-tendencias`.
2.  Indique si desea un área geográfica específica (ej: "Solo España", "Global").

El agente ejecutará el script de tendencias y realizará una búsqueda web complementaria para analizar el debate social asociado a cada tema.
